# Final Demo Paper Set

The original PDF files are intentionally not committed to keep the GitHub repository lightweight.

The reproducible paper list is in `FINAL_DEMO_PAPERS_MANIFEST.json`, and the downloader script is:

```bash
python demo/download_final_demo_papers.py --output-dir data/final_demo_papers
```

Generated demo outputs are already committed under `output/wiki_final_demo/` and `final_submission_research_wiki/vault/`, so reviewers can inspect the final artifact without downloading every source PDF.
