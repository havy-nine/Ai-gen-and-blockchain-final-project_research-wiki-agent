# Open X Embodiment Robotic Learning Datasets and RT X Models

### Open X Embodiment Robotic Learning Datasets and RT-X Models

## Summary
This paper proposes an open, large-scale dataset for robot learning curated from 21 institutions across the globe. The dataset covers diverse behaviors, robot embodiments, and environments, enabling the training of generalized robotic policies.

## Key Claims
- **Generalizable Robot Policies**: We propose a high-capacity model (RT-X) trained on this data that can be adapted to new robots, tasks, and environments.
- **Diverse Data Coverage**: The dataset includes 527 skills across 160,266 tasks from 22 different robotic platforms.

## Source Evidence
The paper is based on a collaboration between 21 institutions. It provides datasets in standardized data formats alongside experimental results demonstrating effective X-robot policies.
