# Project Overview

## Project Title

WorldLand Knowledge Wiki Agent: A Private Research Vault Agent with Blockchain-Style Trust Evidence

## Project Type

Research Productivity Agent with a Blockchain Agent trust layer.

## Target User

A robotics or AI researcher who reads papers regularly and wants to maintain a private Obsidian knowledge graph without manually rewriting every paper into notes.

## Daily-Use Task

The user adds new paper PDFs to `data/sources/`, runs the agent, reviews generated Obsidian notes and Graph View, and checks daily usage/evaluation logs.

## Human Baseline

Without the agent, the user must manually:

- extract paper abstracts and claims,
- create Obsidian notes,
- link related papers,
- check whether summaries are supported by the paper,
- track which papers were processed each day,
- maintain evidence for course/project review.

## Why Keep This After the Course

It is useful as a private research workflow: each run creates notes, graph links, daily logs, evaluation evidence, and a presentation-friendly archive. The user can keep adding papers over time.

## What the Agent Can Do Today

- Ingest PDFs, Markdown, and text files.
- Generate Obsidian-compatible paper pages.
- Build a vault with Home, Research Topics, Pages, Daily Logs, and Evidence.
- Evaluate source-groundedness in basis points.
- Keep failed pages local-only.
- Record mock certificate/payment logs.
- Support mock, local Ollama, and OpenAI providers.
